# Squarie Canvas Simulation v0.α
This is a [website](https://ypactl.github.io/canvas) I made that I've always wanted to show people about, and I'm especially proud of how I coded it. You can see the file size is really, really small, but it will eventually be large as I add to it.
## Squarie Definition
If you do not know what a "squarie" is, it is basically an ASCII-like creature shaped like a square like this: `[╍]`. They look almost like a square, but the ratio is a 3:2, which doesn't fit the term. Unfortunately, a community I was on seems to have lost the "square-shaped" part, so they look like a 5:2 rectangle more than a square, and it looks like this: `[7v7]`.
